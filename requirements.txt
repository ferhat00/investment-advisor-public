# Investment-Advisor tool library — runtime dependencies (Python 3.10+)
# House style: statistics are numpy-only (no scipy/statsmodels by design — see tools/common.py)
#
# Floors are Python-version-gated. Dependabot raises a floor to the newest release, but the
# newest numpy/pandas drop older interpreters while the CI matrix still tests 3.10–3.13:
#   numpy  2.5.1  requires-python >=3.12
#   pandas 3.0.5  requires-python >=3.11
# Without markers `pip install -r requirements.txt` cannot resolve on 3.10/3.11 and CI fails
# before a single test runs. These markers keep Dependabot's intent on modern interpreters
# while leaving 3.10/3.11 installable. If 3.10/3.11 support is dropped, delete the lower
# bounds here AND the matrix entries in .github/workflows/ci.yml together.
numpy>=2.5.1,<3 ; python_version >= "3.12"
numpy>=1.26,<3 ; python_version < "3.12"
pandas>=3.0.5 ; python_version >= "3.11"
pandas>=2.1 ; python_version < "3.11"
yfinance>=1.5.2
lxml>=6.1.1          # yfinance get_earnings_dates dependency (event_calendar.py)
plotly>=6.9.0
